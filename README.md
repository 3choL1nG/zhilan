# 知练 · 人工智能训练师三级刷题工具

知练提供理论练习、实操练习、错题本和模拟考试，支持管理员分配账号和多用户数据隔离。理论答案采用整理的 Excel，实操答案以 PDF 为准；题库及参考资料随项目提供。

## 项目结构

- `zhilan/`：应用源码、运行环境、评分数据和扩展题。
- `刷题工具数据/`：题库、参考答案、实操素材及来源文件。

## 本地运行

需要 Node.js 22.13 或更新版本。

```sh
cd zhilan
node scripts/admin.mjs
node src/server.mjs
```

浏览器访问 `http://127.0.0.1:8787`。首次运行时创建管理员账号并设置密码。题库默认读取相邻的 `刷题工具数据` 目录；可通过 `BANK_DIR` 指定其他位置。网页在线实操还需要 Docker 镜像和独立运行控制器，配置参见 `zhilan/README.md` 的运行结构。

## 答案与限制

- 理论题库 900 题，实操题 40 题；系统卷含题库原题和扩展题。
- 实操以 PDF 原答案为准；18 个代码评分项因原文字符不够清晰需人工核对，不自动判分。小作文和非代码成果也需参照答案自评。
- 扩展题经过校验，但与正式考试难度的可比性尚未认证；本工具不代表官方成绩。
- 在线环境已验证代表性功能，尚未完成七人同时训练的压力认证。
- 题库、参考答案及第三方组件各有来源，公开仓库不改变其原有权利归属。

仓库不包含账号、学习记录、运行文件、数据库或服务器凭据。部署到公网前应自行配置 HTTPS、安全的运行环境及备份。
