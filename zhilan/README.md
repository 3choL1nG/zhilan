# 知练 · 人工智能训练师三级

界面以已确认的 A 优化版为基础。此仓库不包含运行数据库或账号。

## 预览

本机访问 http://127.0.0.1:8787 。登录资料由工作区外的临时凭据文件提供，不随源码分发。

- 理论：900题、题型练习、错题重练、收藏、即时判分。
- 实操：40题、原素材、Notebook、表格与文档、严格填空、PDF答案、文字自评。
- 模拟：官方卷和系统卷、服务端计时、疑题标记、自动保存、断线恢复、到时交卷、历史回顾。
- 管理：分配/停用账号、重置密码、设置临时空间配额、查看用户学习与作答记录。右上角运行任务列表显示实时占用和排队；本人可释放自己的任务，管理员可释放全部。释放只清理运行空间，不交卷、不删已填写答案。

理论标准来自仓库Excel；实操只采用指定PDF。代码仅统一系统换行和去掉整段输入首尾空白，保留内部空格、缩进、引号与变量名。实验运行与正式填空分别保存，运行成功不等于填空正确。

## 运行结构

需要 Node >=22.13（内置SQLite）；服务端无npm运行依赖。浏览器依赖已本地固化在public/vendor，许可证同目录。

```sh
cd /absolute/path/ai_test/zhilan
node scripts/admin.mjs
node src/server.mjs
```

默认 HOST=127.0.0.1、PORT=8787、DATA_DIR=./data。BANK_DIR默认指向同级“刷题工具数据”，使用manifest.json验证来源和派生文件摘要；目录位置变化时明确设置BANK_DIR。

运行控制器必须单独运行，提供受文件权限限制的Unix socket；业务Web进程不需要Docker权限。控制器只接受固定操作，启动无网络、只读系统、删除能力、限制CPU/内存/进程数的容器。`/work`为个人临时空间、`/tmp`另限64MB；原素材只读共享。当前私有测试机4GB内存，MAX_WORKERS=1，多用户排队运行实验；账号数据仍相互隔离。页面显示队列状态。

Docker镜像构建入口 runtime/Dockerfile，直接依赖 runtime/requirements.txt，测试镜像实际安装版本 runtime/requirements.lock.txt。已验证镜像摘要与兼容性结果见上级“开发证据/runtime”。本地预览通过私有SSH Unix socket转发到独立测试控制器，无公网运行接口。隧道或测试机停止时，理论及文字保存仍可使用，实操运行会明确提示失败。

配置入口 src/config.mjs：RUNTIME_SOCKET、RUNTIME_IMAGE、RUNTIME_MEMORY、MAX_WORKERS、BANK_DIR、DATA_DIR。控制器socket默认只允许同组可信业务进程访问，不将其公开为TCP端口。

## 数据与限制

- Excel900题已逐单元格核对一致；扩展300题经过独立验收后启用，系统卷按题型抽取133原题+57扩展题。
- PDF代码转录保留逐页定位。当前211个填空/评分项可自动比对，18个字符仍不够清晰的项明确标为人工核对，既不自动判错，也不输出推断答案。用PDF原页完成自评。尚不能宣称全部代码项已完成逐字认证。
- 非代码成果、报告和小作文使用PDF要点自评，参考总分不代表官方成绩。
- 交卷先事务保存文字、自动分及题目版本，再执行临时文件清理；失败清理进入重试队列。练习结束同样清理，异常空闲30分钟回收。需要的模型、图片、表格和文档请结束前下载。
- 仅文字/正式填空/Notebook代码/文档文字与成绩长期保存；临时上传与生成文件不长期留存。历史考试保留当时题目答案快照。
